# برنامج السنتر في لوحة الإدارة

الصفحة `/admin/center-desktop` موجودة في كود موقع مسار، وتظهر في القائمة تحت «التقارير والمتابعة» باسم «برنامج السنتر»، وكذلك في روابط الصفحة الرئيسية للإدارة. لا تعني هذه الوثيقة أن الخدمة منشورة أو مربوطة فعليًا.

## الاستخدام

- «النسخ والمشاكل»: عرض معرّف السنتر، دور الجهاز الرئيسي/الفرعي، النظام، إصدار البرنامج، حجم النسخة ووقت استلامها بتوقيت القاهرة.
- البحث بمعرّف السنتر أو الرفع أو الإصدار، مع تصفية الرئيسي/الفرعي وويندوز/ماك. البحث والترتيب الزمني يشملان النسخ المحمّلة فقط؛ زر «تحميل المزيد» يتابع مؤشر الخدمة دون افتراض أن ترتيب UUID ترتيب زمني.
- «تفاصيل المشاكل»: أحداث النسخة المختارة فقط، مع نوع الخطأ وكوده ووقت حدوثه وإصدار البرنامج وتفاصيل فنية قابلة للتوسيع. افتراضيًا تُعرض الأخطاء دون أحداث بدء التشغيل. عند تجاوز الحد تُعرض ملاحظة بعدد الأحداث غير المعروضة.
- «تنزيل السجل المعروض» يصدّر الأحداث المصفاة ومعلومات الرفع؛ لا يتضمن قاعدة البيانات. «تنزيل النسخة» إجراء منفصل يعيد الملف الخاص الكامل للإدارة. النسخة المرفوعة من الفرعي تشخيصات فقط.
- «إصدارات البرنامج» يعرض الحالات الأربع: ويندوز/ماك × رئيسي/فرعي. الحالات تفرق بين إصدار متاح، إصدار لم ينشر، وملف غير صالح. تُحمّل الإصدارات عند فتح هذا القسم؛ فحصها لا يؤخر قائمة النسخ. عرض الإصدار لا يثبت تنزيله أو تثبيته على جهاز.
- زر «تحديث» يعيد القراءة. البيانات ليست بثًا مباشرًا لحالة اتصال الأجهزة؛ الأحداث تخص آخر رفع اختاره المستخدم. فشل الربط أو التحميل له رسالة منفصلة عن حالة عدم وجود نسخ.

## الصلاحيات والربط

الصفحة ومسارات الموقع تتطلب دور `Admin`. الحساب العادي داخل برنامج السنتر ما زال يستطيع طلب الرفع طبقًا لصلاحيات التطبيق؛ ذلك لا يمنحه وصولًا لنسخ جميع السناتر في الموقع. رموز خدمة النسخ لا تصل إلى المتصفح. [توثيق إعداد خادم الموقع ومساراته](../../backend/docs/center-desktop-support.md).

تظل SQLite على الجهاز الرئيسي مصدر بيانات التشغيل. الصفحة لا تعدل البيانات المرفوعة ولا تستعيدها على الأجهزة، ولا تثبت تحديثات ولا تنشرها. لا توجد تغييرات على مخطط قاعدة بيانات الموقع.

## التحقق المحلي — ٣ أكتوبر ٢٠٢٦

- ٥ اختبارات متصفح ببيانات صناعية تغطي الوصول الإداري، رفض مساعد/مشرف محدود الصلاحيات، البحث والتصفح والتفاصيل والإصدارات، انقطاع الخدمة وإعادة المحاولة، ومنع ظهور استجابة نسخة قديمة داخل تفاصيل النسخة الجديدة.
- ٣١ اختبارًا لمسارات الموقع باستخدام MVC/JWT الفعليين واستبدال اتصال HTTP الخارجي فقط؛ بناء API ناجح.
- ١٧ اختبارًا أساسيًا بخدمة Go مع حالات متعددة، وفحص التزامن والتحليل الثابت ناجحان.
- بوابة تسجيل مسارات الإدارة نجحت: ١٢ اختبارًا لاستخراج استدعاءات الواجهة، و٣٠ اختبار Python، مع تحديث سجلات المسارات فقط. تنزيل النسخة الكاملة مصنّف كتصدير حساس ومحظور على وكيل الذكاء الاصطناعي.
- تحليل الويب ونوعيات TypeScript وبناء الموقع نجحوا محليًا. فُحصت صور سطح المكتب والهاتف ببيانات صناعية.

لم يحدث نشر أو رفع بيانات تشغيل أو تغيير قاعدة مستخدم. إخفاقات اختبارات برنامج Flutter المذكورة في [التقرير السابق](../../desktop/center-flutter/docs/support-release-verification-20261003.md) لا تُعتبر محلولة بإضافة صفحة الويب.

اختبارات المتصفح لها إعداد مستقل `playwright.center-desktop.config.ts` بدون تهيئة/زرع قاعدة E2E، وتستبدل حدود API فقط. إعداد خادم الدعم الخاص يجب أن يكتمل قبل أن تستقبل الصفحة بيانات حقيقية.
