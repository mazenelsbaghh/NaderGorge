# MIM game asset provenance

- `vendor/`: Three.js modules bundled from the existing reviewed `output/mim-3d` prototype. The upstream MIT license is preserved in `THREE-LICENSE` and `vendor/LICENSE`.
- `assets/mim.png`, `assets/limestone.png`, and `assets/arabic.woff2`: existing Massar MIM prototype assets copied from `output/mim-3d` in this repository.
- The public game directory contains only generic renderer code and art assets. Lesson titles, questions, choices, explanations, source references, user identity, and progress namespace arrive at runtime from the authenticated parent page.
