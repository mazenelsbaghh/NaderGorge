# مراجعة سجل المشاكل — ٥ أكتوبر ٢٠٢٦

المصدر: سجل التشخيصات المرفوع يوم ٤ أكتوبر الساعة ٠٣:٥٢ بتوقيت القاهرة، لإصدار 1.1.0+2. يحتوي على ٨٤ حدثًا منها ٧٥ حدثًا مصنفًا تاريخيًا كخطأ. تمت قراءة الـ٧٥ كاملة دون حذفها أو تعديل بيانات الطلاب.

| التصنيف | العدد | النتيجة |
| --- | --- | --- |
| ui.warning | ٥٩ | تنبيهات واجهة؛ المصدر يسجلها عمدًا كـCenterException. فصلها العرض الجديد عن الأخطاء مع إبقائها تحت عرض جميع الأحداث. |
| ui.attendance_workspace | ٥ | بدون كود سبب أو موضع خطأ؛ التشخيص غير محسوم. |
| ui.reports_page | ١ | بدون كود سبب أو موضع خطأ؛ التشخيص غير محسوم. |
| lan.command | ٦ | بدون كود سبب أو موضع خطأ؛ التشخيص غير محسوم. |
| lan.login | ١ | بدون كود سبب أو موضع خطأ؛ التشخيص غير محسوم. |
| auth.sign_in | ١ | بدون كود سبب أو موضع خطأ؛ لا يثبت عطلًا برمجيًا أو كلمة مرور خاطئة. |
| cloud.updates | ٢ | OtherError بدون السبب أو الموضع. إصدار 1.2.1+4 أصلح مشكلة ضغط نقل التحديث المثبتة مستقلاً، لكن السجل القديم لا يثبت أنها سبب هذين الحدثين. |

كل الأحداث عدا التحديثات من إصدار 1.0.0+1. لا يصح عرضها كـ٧٥ مشكلة مفتوحة في الإصدار الحالي أو إعلان حل الأسباب المفقودة.

## الإصلاحات المحلية

- عرض مجموع الأخطاء والتنبيهات منفصلين، وإبقاء التنبيهات قابلة للعرض والتصدير.
- إخفاء كود null مع إبقاء الكود صفر صالحًا. توضيح أن السجل تاريخي وأن الأحداث بلا أسباب تحتاج رفعة جديدة عند تكرارها.
- إضافة diagnosticCode اختياري رقمي لاستثناءات المجال دون تسجيل رسائل المستخدم أو بياناته، والحفاظ على سلسلة السبب.
- أكواد حالية: 1101 صلاحيات، 1102 رفض بيانات الدخول، 1201 حصة مغلقة أو ملغاة، 1202 حصة ملغاة، 2101 رفض تفويض التحديث، 2102 رد تحديث غير ناجح، 2103 فشل صيغة/حجم/بصمة التحديث، 2104 تعذر الشبكة أو انتهاء المهلة، 2199 سبب تحديث غير مصنف (تظل سلسلة السبب محفوظة).

نجح ٣٧ اختبارًا للسجل والتحديثات و٧ اختبارات متصفح، بما فيها سيناريو ٥٩ تنبيهًا و١٦ خطأ مع أكواد null. هذه التعديلات محلية ولم تُبنَ أو تُنشر ضمن إصدار أحدث من 1.2.1+4 حتى كتابة التقرير. لا تتغير السجلات القديمة بأثر رجعي.
