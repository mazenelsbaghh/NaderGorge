# تنبيه تكرار الحضور

التنبيه يعمل عند محاولة تسجيل الدخول أو التحصيل، وليس عند البحث أو عرض سجل الطالب.

- نفس الطالب في نفس الحصة: يظهر تنبيه بتفاصيل التسجيل السابق، ولا يُنشأ حضور أو دفع أو استهلاك باقة جديد.
- نفس الطالب في أي حصة تحمل نفس الرقم، حتى لو اختلفت المجموعة أو المادة أو الصف أو اليوم: تظهر نافذة بالمجموعة ورقم الحصة وتاريخها ووقت التسجيل السابق، مع حالة الحضور أو التعويض.
- Enter أو Esc يرجع دون تسجيل. المتابعة من زر «متابعة رغم الحضور السابق» فقط. إدخال كود جديد أثناء النافذة يمنع الموافقة ويطلب الرجوع ثم مسح الطالب من جديد.
- تظهر النافذة عند Enter للتسجيل، وزري دفع الحصة والشهر، واختصارات L/M، والتعويض. البحث وحده والكارت والملاحظات وعرض السجل لا يوقفهم تنبيه الحضور.
- الحضور الملغي والحصص الملغاة والغياب لا تُعد حضورًا سابقًا. إعادة تحصيل حضور قائم أُلغي دفعه تبقى متاحة؛ فهي تسوية نفس الحضور.
- إلغاء الحضور مع الاحتفاظ بدفع الحصة ثم تسجيله مجددًا يستخدم الدفع المحفوظ دون تحصيل ثانٍ، بعد مراجعة أي حضور متعارض آخر.

## الحفظ والربط

يفحص الجهاز الرئيسي الحضور مرة أخرى داخل العملية قبل إنشاء الدفع أو استهلاك الباقة. موافقة المستخدم تُرسل كقائمة محددة للتسجيلات التي راجعها؛ تغيّر تلك القائمة أثناء النافذة يوقف التسجيل ويطلب المراجعة من جديد. لا تمنح الموافقة صلاحية عامة أو مستقبلية لتجاوز التنبيه. يُحفظ قبول الحضور السابق في سجل العملية مع الموظف ومعرّفات التسجيلات السابقة.

الاختصارات تحفظ بيانات الدفع المؤكدة، والتسجيل المباشر الذي يعرض تنبيهًا يحفظ تسعيرته قبل انتظار الموافقة؛ تغيّر السعر أو الخصم أو تغطية الباقة أثناء المراجعة لا يسمح بتحصيل مبلغ لم يُراجع. الربط المحلي ينقل المراجعة للجهاز الرئيسي ويستعمل حماية إعادة تنفيذ العمليات القائمة.

## التحقق

تستعمل الاختبارات قواعد SQLite مؤقتة واتصالات Go/TLS فعلية. تشمل مراجعة الحضور عبر المجموعات والأيام والمواد، حضور التعويض والحصص المجانية والإضافية، منع الدفع واستهلاك الباقة قبل الموافقة، تزامن جهازين، تغير قائمة الحضور، فقد الرد والمصالحة، إعادة التشغيل والنسخ الاحتياطية، والعرض والكيبورد والاسكانر. النتائج النهائية وبصمات الحزمة تُسجل في `build/verification/duplicate-attendance-result.json` بعد اكتمال الاختبارات والبناء.

لم تُفتح قاعدة بيانات المستخدم أثناء التطوير والتحقق. حزمة التجربة مخصصة لـMac Apple Silicon؛ تجربة جهازين Windows فعليين تظل خطوة منفصلة.
