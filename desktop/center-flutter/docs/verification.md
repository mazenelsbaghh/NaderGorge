# تحقق النسخة المحلية — ٢ أكتوبر ٢٠٢٦

تم التحقق على macOS باستخدام Flutter 3.41.0 وDart 3.11.0.

- الربط المباشر بالكود ونسخة الفرعي دون SQLite: نجحت **٥٤٠/٥٤٠ حالة** في المجموعة الكاملة، والتحليل دون ملاحظات. تفتح نسخة الفرعي شاشة الربط مباشرة دون قراءة حساب التثبيت، وتعرض اسم الرئيسي وبصمته ثم تقبل الكود وEnter؛ اختيار صريح عند تعدد الأجهزة ولا تجربة للكود على كل الأجهزة. أُثبت الرجوع التلقائي بعد إعادة تشغيل الرئيسي بنفس هوية الجهاز وإعدادات الربط المحفوظة، وتوقف التحصيل أثناء الانقطاع، وعدم إنشاء SQLite أو WAL أو SHM أو حفظ حسابات/لقطات طلبة على الفرعي، مع الحفاظ على ملفات التجربة القديمة دون فتحها. بُني الرئيسي `5e94cb70767b2ae5` والفرعي `2e0428e0604b6f52` بشكل مستقل؛ سجلات المترجم تثبت وضع الفرعي، والحزمة الفرعية بلا ملف حساب مدير أو قاعدة بيانات. نجح التوقيع وCRC وهوية AOT لكل دور مع المصدر والاختبارات ثابتة. التنزيلان بلاحقة `-code`، والتفاصيل في `build/verification/code-link-result.json`. لم تُفتح قواعد المستخدم أو تُشغّل التطبيقات؛ تجربة Finder على جهازين والراوتر الفعلي ما زالت عند المستخدم.

- إصلاح تجهيز هويات ماك واستعادة الربط: نجحت **٦٩ حالة مركزة** (٤٨ لخدمات الشبكة والتخزين والتشخيص، ٨ لشاشة الربط، و١٣ لتصدير اللوج)، والتحليل دون ملاحظات. تعرض الشاشة خطوتين لبيانات الرئيسي ثم الكود، وتميز إدخال ستة أرقام في الخانة الأولى، وتعرض مسار إعادة البحث/الربط اليدوي مع إرشاد إذن macOS وتصدير سجل منقح قبل تسجيل الدخول. جُمّع مشغّل مستقل لكل دور بــUUID مختلف، ونجح توقيع Apple Development لكل التطبيق والأطر وخدمة Go مع فحص التوقيع وCRC ومنع البيانات الخاصة داخل الحزم. بقت هويتا التخزين القديمتان لحفظ بيانات التجربة، ولم تتغير ملفات التطبيقات القديمة التي يشغّلها المستخدم. معرّف التطبيق **1fbb911dabd22a0b**، والنتائج وبصمات الحزمتين الجديدتين `-fixed` في `build/verification/lan-recovery-result.json`. المصدر ثابت بين الفحص والبناء؛ لم تُفتح قاعدة المستخدم. السبب الدقيق لخطأ Socket على الماك الثاني لم يصل لوجهة التطوير، وتصحيح تجهيز الهوية لا يعد إثباتًا لنجاح الاتصال الفعلي: تجربة التطبيق من Finder على الجهازين بعد السماح بالشبكة المحلية ما زالت عند المستخدم.

- تحديث تنبيه تكرار الحضور وحزم تجربة جهازين ماك: نجحت **٥٢٥ اختبارات كاملة**، منها **٢٠ جديدة** (٩ لقواعد SQLite و٩ للواجهة و٢ للربط الحقيقي عبر Go/TLS)، والتحليل دون ملاحظات. نفس الحصة يمنع تكرار الحضور والدفع؛ أي حصة بنفس الرقم عبر المجموعات والأيام تتطلب مراجعة نافذة التفاصيل ثم زر متابعة صريح. تشمل الحالات الكيبورد والاسكانر، تغير السعر والحضور أثناء المراجعة، تزامن الجهازين وفقد الرد، إعادة التحصيل والحضور الملغي، إعادة التشغيل والنسخ الاحتياطي. المصدر والاختبارات ثابتان عبر الفحص والبناء؛ معرّف الماك **78e1b997db02407a** وفحص التوقيع وCRC متحقق منهما. حزمتا Apple Silicon للتجربة معزولتان عن بيانات النسخة الأساسية بهويتي `com.massar.lantrial.primary` و`com.massar.lantrial.secondary`، وتضمان ملف تعليمات عربي. النتائج والبصمات في `build/verification/duplicate-attendance-result.json`؛ التفاصيل في [تنبيه الحضور](duplicate-attendance.md) و[تجربة جهازين ماك](mac-lan-trial.md). لم تُفتح قاعدة المستخدم ولم يُختبر جهازان ماديان أثناء إعداد الحزم.
